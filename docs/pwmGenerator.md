# PWMgenerator

Генератор ШИМ заданной частоты и скважности. Выход — **второй пин слота**
(`SLOTS_PIN_MAP[slot][1]`), тот же, что у `PPMservo`.

```ini
[SLOT_3]
mode = PWMgenerator
options = frequency:25000, startDuty:0
crosslink = artNetCrosslink_5/event/ch_0/val:@ -> pwm_3/action/setDuty:@/2.55
```

## Опции

| Опция | Тип | По умолчанию | Диапазон | Смысл |
|---|---|---|---|---|
| `frequency` | int, Гц | 1000 | 10–100000 | Частота ШИМ |
| `inverse` | flag | off | — | Аппаратная инверсия выхода |
| `startDuty` | int, % | 0 | 0–100 | Скважность при старте |
| `defaultState` | int | 1 | 0–1 | 0 — модуль спит до `action/enable 1` |

## Команды и события

```
pwm_3/action/setDuty    42        скважность в процентах, дробные допустимы
pwm_3/action/enable     0|1       спать / работать
pwm_3/event/enable      1         состояние модуля
pwm_3/event/duty        42        текущая скважность
```

Спящий модуль держит выход в покое (duty 0); при `inverse` аппаратная инверсия
сама поднимает пин в единицу, так что активная-низким нагрузка остаётся
выключенной.

## Общий таймер с сервоприводами

**Модуль делит LEDC-таймер 1 с `PPMservo` — вместе в одной конфигурации они не
работают.**

Таймеров LEDC у esp32s3 четыре, нулевой намертво занят светодиодными модулями с
их 5 кГц. Частоту в LEDC задаёт **таймер**, а не канал, поэтому все потребители
одного таймера делят одну частоту: генератор, настроив таймер на свою частоту,
уводит у сервы её 50 Гц.

Модуль проверяет конфигурацию на старте и, найдя слот с `PPMservo`, пишет в лог
ошибку с номерами обоих слотов. Работать при этом не отказывается — делает то,
что попросили, но громко предупреждает.

Несколько слотов `PWMgenerator` сосуществуют нормально: у каждого свой канал
LEDC и своя скважность, **но частота у них общая** — последний стартовавший слот
перенастраивает таймер. Если частоты в конфигурации разные, в лог уходит ошибка
с обеими величинами.

## Разрешение зависит от частоты

Число шагов скважности ограничено сверху величиной `тактовая / частота`:

| Частота | Разрядность | Шагов | Шаг скважности |
|---|---|---|---|
| до 4.8 кГц | 14 бит | 16384 | 0.006 % |
| 20–25 кГц | 11 бит | 2048 | 0.05 % |
| 50 кГц | 10 бит | 1024 | 0.1 % |
| 100 кГц | 9 бит | 512 | 0.2 % |

Разрядность выбирается автоматически, максимально возможная для запрошенной
частоты. Фактическое значение уходит в лог при старте:

```
I PWM_GEN: [pwm_3] ready: pin 8, 25000 Hz, 11 bit (2048 steps), inverse 0, startDuty 0%
```

Даже на 100 кГц 512 шагов дают запас точнее, чем целые проценты команды
`setDuty`, так что на практике разрешение ограничением не становится.
